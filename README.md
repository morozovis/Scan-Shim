
# Scan Shim

Клавиатура-прокладка для Android-терминалов сбора данных (проверено на **АТОЛ Smart.Pro / AtolOS 1.0, Android 9**). Принимает код от сканера через Broadcast Intent и вставляет его в поле ввода целиком, **вместе с управляющими символами GS (0x1D)**, после чего нажимает Enter.

Нужна для работы с кодами **Честного знака** (GS1 DataMatrix) в веб-приложениях и формах, которые читают сканер как клавиатуру: например, в проверке сканера и приёмке в «Моём складе».

## Зачем это нужно

Код маркировки содержит разделители GS. У GS нет клавиши, поэтому, когда терминал «печатает» код клавишами (режим Keyboard / Scan Wedge), разделители теряются. Код приходит укороченным (127–128 символов вместо 129) и сервис его не принимает. При этом сам сканер код читает правильно (в ScanDemo GS виден).

Scan Shim обходит проблему: код берётся из Intent целиком и передаётся в поле как готовый текст.

## Возможности

- Вставка кода со всеми символами GS и Enter в конце.
- Работает во всех приложениях и браузерах, где есть поле ввода.
- Виджет и аппаратная кнопка сканирования не затрагиваются: лазер и подсветку включает штатный сервис терминала.
- Встроенная клавиатура для обычного набора: русская и английская раскладки, цифры и символы, Shift, Ввод, пробел, Backspace. В числовых и телефонных полях сразу открываются цифры.
- Два способа вставки: текстом (по умолчанию) и через буфер обмена (как делает Миндео).
- Экран диагностики: длина последнего скана, число GS, сам код с подсвеченными `<GS>`.

## Как это работает

1. Терминал сканирует код и отправляет Broadcast Intent (на Атоле: action `com.hht.scanwedge`, данные в `com.hht.datawedge.data_string`).
2. Scan Shim работает как метод ввода (IME) и принимает этот Intent.
3. Код вставляется в активное поле через `InputConnection` целиком, затем отправляется Enter.

Пока клавиатура выбрана активной, сервис работает постоянно. Если в данный момент нет поля ввода, скан некуда вставлять, и в диагностике появится пометка «нет поля ввода».

## Сборка

Нужна Android Studio (бесплатная) и интернет для первой синхронизации Gradle.

1. File → Open → выберите папку проекта (где лежит `settings.gradle`).
2. Дождитесь окончания Gradle sync.
3. Build → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Параметры: minSdk 26 (Android 8.0), targetSdk 28, Java 8, без внешних зависимостей.

## Установка

1. Скопируйте `app-debug.apk` на терминал (USB, почта, облако).
2. Откройте файл и разрешите установку из неизвестных источников, если попросит.
3. При обновлении лучше сначала удалить старую версию: если APK собран на другом компьютере, подпись отличается, и поверх он не встанет.
4. Откройте **Scan Shim** и нажмите:
   - **«1. Включить клавиатуру Scan Shim»** и включите её в списке;
   - **«2. Выбрать её активной»** и выберите Scan Shim.

Дальше она остаётся клавиатурой по умолчанию. Сменить её можно в системных настройках: Настройки → Система → Язык и ввод → Виртуальная клавиатура.

## Настройка терминала Атол

В приложении настроек сканера:

| Параметр | Значение |
|---|---|
| Scan Wedge | включён (нужен виджету и лазеру) |
| Send barcode data | **None** |
| Broadcast Intent | **включён** |

Значения Intent смотрите в **BROADCAST INTENT SETUP**. У Атола это:

- Action: `com.hht.scanwedge`
- Category: `android.intent.category.DEFAULT`
- Scan Data Label: `com.hht.datawedge.data_string`

## Настройка Scan Shim

Эти значения стоят по умолчанию. Если у вашего терминала другие, измените их и нажмите «Сохранить».

| Поле | По умолчанию | Описание |
|---|---|---|
| Broadcast action | `com.hht.scanwedge` | Action Intent от сканера |
| String extra | `com.hht.datawedge.data_string` | Поле с текстом кода |
| Bytes extra | `scandata_array` | Запасное поле с байтами (UTF-8), если текстового нет |
| Режим | commit | **commit** вставляет текст напрямую. **paste** кладёт код в буфер и вставляет командой «Вставить» (как Миндео) |
| Нажимать Enter | вкл. | Enter после кода |

Для терминалов Миндео (если они отправляют Intent): action `com.android.scanner.broadcast`, extra `scandata`.

## Проверка

1. Откройте любую страницу с полем ввода и нажмите на поле. Внизу появится клавиатура Scan Shim.
2. Отсканируйте код Честного знака. Он должен вставиться целиком и закончиться Enter.
3. Откройте приложение Scan Shim. В блоке «Последний принятый скан» будет, например: `длина=129 GS=2` и код с метками `<GS>`.

Для коротких кодов длина равна длине содержимого без Enter. Типичный код Честного знака содержит 2 GS.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| «Последний принятый скан» пустой | Intent не доходит. Проверьте action и extra в BROADCAST INTENT SETUP, убедитесь, что Broadcast Intent включён, а Send barcode data = None. Intent с категорией DEFAULT принимается |
| Запись есть, но в поле пусто (`нет поля ввода`) | Нет курсора в поле. Нажмите на поле до сканирования |
| Код вставляется, но GS нет | Попробуйте режим paste. Проверьте число GS в «Последнем принятом скане»: если там 0, сканер не передаёт GS в Intent |
| Код вставляется дважды | Помимо Intent, терминал ещё и печатает клавишами. Установите Send barcode data = None |
| Клавиатура не появляется | Проверьте, что Scan Shim выбрана активной (кнопка 2) и поле ввода в фокусе |
| После обновления прежняя версия | Удалите приложение, установите заново, снова включите и выберите клавиатуру |
| Нет нужной раскладки | Сейчас RU/EN и цифры/символы. Для остального переключитесь на другую клавиатуру в системных настройках |

## Ограничения

- Встроенная клавиатура базовая: нет автоисправления, подсказок слов, смайлов и голосового ввода.
- Скан вставляется только в поле с фокусом.
- Отладочная сборка (debug), без подписи для публикации.
- APK в репозитории есть, при желании можно собрать самому.
